誤差模型

每種 fix 的水平誤差是白雜訊 σ_h 加一階 Gauss-Markov 偏差（bias_σ, τ），E、N 各自獨立。每軸 σ = √(σ_h² + bias_σ²)；95 % 半徑 R95 = 2.448 σ，DRMS = √2 σ。
